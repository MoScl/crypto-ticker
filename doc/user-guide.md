# CryptoTicker 用户手册

> 面向最终用户的功能使用说明。

## 1. 安装与启动

### Windows

1. 运行 `CryptoTicker Setup x.x.x.exe`，按向导选择安装目录（默认按用户安装，无需管理员权限）。
2. 首次启动如遇 SmartScreen 提示「Windows 已保护你的电脑」，点击「更多信息 → 仍要运行」即可（应用未做代码签名）。
3. 启动后小窗出现在屏幕上，同时在系统托盘出现图标。

### macOS

双击 `CryptoTicker-x.x.x.dmg`，将应用拖入 Applications。首次打开若提示无法验证开发者，请右键应用 →「打开」。

### 开发版运行

```bash
npm install && npm run dev
```

## 2. 界面总览

```
┌────────────────────────────┐
│ 💚 Crypto     [─] [⚙] [✕]  │  ← 标题栏：拖拽移动；按钮=最小化/设置/隐藏
│ ──────────────────────────  │
│  BTC  ¥...  $117,xxx  +2.1%│  ← 币种行：价格 + 24h 涨跌幅
│  ETH  ...                   │     （涨=红色，跌=绿色）
│  ...                        │
│ ● 数据源: OKX   更新于 3 秒前 │  ← 状态栏：数据源健康 + 刷新时间
│ [搜索币种____] [📊] [☑]      │  ← 底部操作条：搜索 / 榜单弹窗 / 多选
└────────────────────────────┘
                    ⇲  ← 右下角缩放手柄
```

- **移动窗口**：按住标题栏拖拽。
- **缩放窗口**：拖动右下角手柄；尺寸会自动记住。
- **隐藏窗口**：点 ✕ 隐藏到托盘（不退出）；托盘点击恢复。

底部操作条（从左到右）：**搜索框**（输入符号弹出联想列表，回车添加第一个匹配）· **榜单按钮**（柱状图图标，打开添加币种弹窗）· **多选按钮**（勾选图标，进入批量操作模式）。

## 3. 自选列表管理

| 操作 | 方式 |
|---|---|
| 搜索添加 | 底部搜索框输入符号（如 BTC），点联想项或回车直接添加 |
| 浏览榜单添加 | 点底部柱状图按钮打开弹窗，在 7 个榜单 Tab 中点行尾「＋」 |
| 删除币种 | 进入多选模式 → 勾选要删的行 → 点「移除」→「取消」退出 |
| 调整顺序 | 按住币种行左侧拖拽到目标位置 |
| 查看交易 | 点击币种行展开「查看交易」平台条；行尾 ↗ 直接跳转 |

**7 大榜单**（添加弹窗 Tab）：主流币 / 热门榜（CoinGecko trending）/ 涨幅榜 / 跌幅榜 / 新币榜 / 市值榜 / 成交额榜，各取前 15 名，已在监控列表中的币显示 ✓。

## 4. 行情与数据源

- **实时模式**（默认）：Binance WebSocket 推送，价格毫秒级更新。
- **轮询模式**：设置中可切换为定时刷新（最小 5 秒）。
- **多源容灾**：数据源选「自动」时，主源故障自动切换 OKX → Binance → Bybit → Gate → CoinGecko，无感恢复；单个源连续失败会暂时熔断 2 分钟。
- **状态栏读法**：
  - 绿点 = 数据源正常（实时）；黄点 = 降级中（有数据但走兜底通道，如 WS 断线走 REST）；红点 = 暂无数据。
  - 「更新于 X 前」超时增大说明网络波动，可打开网络面板诊断。

## 5. 设置面板（⚙）

| 设置项 | 说明 |
|---|---|
| 语言 / Language | 中文 / English 即时切换并记住 |
| 数据源 | OKX / Binance / Bybit / Gate.io / CoinGecko / 自动 |
| 计价币 | USDT / USDC / FDUSD |
| 刷新模式 | 实时 / 轮询（间隔秒数） |
| 代理 | `http://127.0.0.1:7890` 或 `127.0.0.1:7890`；留空则自动探测 |
| 透明度 | 30% – 100% |
| 窗口置顶 | 开关 |
| 点击穿透 | 开关（见下节） |
| 开机自启 | 开关 |

## 6. 点击穿透（核心特色）

开启后鼠标点击会**穿透窗口直达下层应用**——小窗变成纯展示的「贴纸」，完全不挡操作。

- **开关方式**：设置面板 / 托盘右键菜单 / 全局快捷键 **`Ctrl+Shift+X`**（任何状态下可用，包括穿透态）。
- **智能交互**：穿透开启时，鼠标移到右上角按钮区域或打开设置面板，窗口会临时恢复可交互，移开后又回到穿透——既能操作，又不挡鼠标。
- **退出穿透**：`Ctrl+Shift+X`，或移到右上角点退出按钮。

## 7. 一键跳转交易所

点击币种行展开「查看交易」平台条（再点收起），或点行尾 ↗：直接在浏览器打开该币在 Binance / OKX / Gate.io 的现货交易页（添加弹窗的榜单行同样支持）。

跳转链接仅允许官方交易所域名（白名单校验），不会跳到第三方站点。

## 8. 网络诊断面板

点击状态栏左侧网络指示灯打开面板，可查看：

- 在线状态、网络类型（WiFi/以太网）、网卡名、本机 IP
- **当前出口**：走代理（地址+延迟）还是直连（DoH 解析）
- 降级状态：本地网络通但国际站点不可达（典型：代理未生效）
- DNS 劫持检测：系统 DNS 解析失败但 DoH 可用时会标记

**连不上网时**：优先在设置中填写代理地址；不填也会自动依次探测——你配置的代理 → 系统代理 → 本地常见代理端口（7897/7890/1080 等）→ DoH 直连。

## 9. 托盘与退出

- 托盘左键：显示/隐藏小窗
- 托盘右键：切换点击穿透 / 显示小窗 / 退出
- **退出必须走托盘 → 退出**（点窗口 ✕ 只是隐藏）。再次双击安装包会被单实例锁拦下并聚焦已有窗口。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 价格不更新、状态灯变黄/红 | 打开网络面板看出口；填代理或等待自动容灾切换 |
| 穿透开启后按钮点不了 | 把鼠标移到右上角按钮区域等高亮出现；或直接 `Ctrl+Shift+X` 关穿透 |
| 界面变成英文了 | 设置 → 语言 → 中文 |
| 找不到窗口 | 托盘左键唤回；可能被穿透+隐藏了 |
| 想恢复默认 Top 10 列表 | 添加弹窗「主流币」Tab 逐个添加即可 |
